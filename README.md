# Interactive Cursor-Driven Emoji Animation

A smooth, interactive cursor animation website built with HTML, CSS, and vanilla JavaScript. The page shows a fullscreen dark-green field of sleeping emoji-like characters that wake up, glow, look toward the cursor light, and gently move away when disturbed.

## Features

- Fullscreen responsive interactive scene
- 24 custom SVG emoji characters
- Smooth cursor-following light effect
- Distance-based wake and sleep animation
- Sad/drowsy facial expression while waking
- Pupils track the cursor position
- Nearby emojis gently move away from the cursor
- Touch and pointer support
- No frameworks, backend, or external dependencies

## Upload To GitHub

1. Create a new repository on GitHub named:

```text
Interactive-Cursor-Driven-Emoji-Animation
```

2. In this project folder, run:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/Interactive-Cursor-Driven-Emoji-Animation.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username.

## GitHub Pages

To publish it as a live website:

1. Open your GitHub repository.
2. Go to **Settings**.
3. Open **Pages**.
4. Set source to **Deploy from a branch**.
5. Select branch **main**.
6. Select folder **/root**.
7. Save.

Your site will be available at:

```text
https://YOUR_USERNAME.github.io/Interactive-Cursor-Driven-Emoji-Animation/emoji-cursor-demo/
```
